# Gyaan Setu 📚

Gyaan Setu is an offline AI tutor designed to help Class 9 students learn through simple, clear, and step-by-step explanations.

The project uses a locally running AI model through Ollama, so questions can be answered without relying on a cloud AI API.

## ✨ Features

- 🤖 AI-powered tutoring for Class 9 students
- 📚 Simple and student-friendly explanations
- 🧮 Step-by-step mathematics solutions
- 🌐 Supports English, Hindi, and Hinglish conversations
- 🔒 Runs with a locally hosted AI model
- ⚡ Web-based chat interface
- 🩺 Backend health-check endpoint
- 🚫 No external AI API required
